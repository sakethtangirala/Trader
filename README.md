AI stock trading tool using Lumibot, a backtesting and trading library, as well as FinBERT, an NLP model to analyze financial sentiment.

The algorithm's output controls the model's buying/selling decisions, and it is dependent on Yahoo's stock market data/news for sentiment and stock values. 

**DISCLAIMER**
* API_KEY, API_SECRET and BASE_URL must be defined before use.
* "symbol" can be modified to any company abbreviation.
